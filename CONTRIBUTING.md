# Contributing

Thanks for your interest in ai-storyboard-planner!

## Reporting issues

Open a GitHub issue with:

- What you ran (command + input JSON)
- What you expected
- What happened instead

## Pull requests

1. Fork the repo and create a feature branch.
2. Keep the tool dependency-free (Python standard library only).
3. Add or update tests for behavior changes: `python -m unittest test_storyboard -v`
4. Describe the change and why it helps a production workflow.

## Maintainer workflow

Releases are cut from `main`. The maintainer reviews pull requests, triages
issues weekly, and tags a release whenever the roadmap items land.
